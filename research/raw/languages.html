The Tournament Director is available in English only. However, the software is internationalized, and anyone may modify the language files in order to support a particular language. Some users of the Tournament Director software have translated much of the program and have been kind enough to share their translations with other users, free of charge. Please note that these translations may be incomplete.
To install a language pack, first download the language pack. Next, open the Tournament Director application and select the Preferences tab. Press the Language button. Next press the Install Language Pack. Then select the downloaded language pack file.
Please note the following items:
  • These language packs only work with version 3.7 or later

    If you are still using an older version please click here.

  • Any language pack may be used with any version of the software

    The version number indicates the version for which it was originally created or last updated.

  • You only need 1 language pack for any given language

    Several language packs are available for some languages due to the fact that several people have contributed their own translations. But you only need one. Choose the one intended for a version of the Tournament Director software that is closest to the version you are using.

Interesting in translating the software?
If you are interested in translating the Tournament Director application, whether just for yourself or to contribute for others to enjoy as well, please email [email protected]. I will be happy to provide instructions and guidance.
